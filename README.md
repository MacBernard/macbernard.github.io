# MacBernard Soft Solutions Limited

Software development company based in Gombe State, Nigeria. We build practical, affordable software for small-scale businesses in Gombe State and its neighboring states: businesses that want to operate digitally but cannot justify complex, enterprise-priced systems.

**Live site:** https://macbernard.github.io/

## What we build

- Custom business software (sales, stock, customers, staff, money records)
- School management systems, including **MacHub** (schools), **MacSuite** (hotels) and **MacPOS** (point of sale)
- Websites for business
- Records digitization
- Ongoing support and maintenance
- Digital adoption guidance for small businesses

## Stack

The site is a dependency-free static page (HTML + CSS + vanilla JS), published with GitHub Pages.
